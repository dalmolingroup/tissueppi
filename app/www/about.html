About TissuePPI

TissuePPI is an interactive web application designed for visualizing and analyzing tissue-specific protein-protein interaction (PPI) networks. Built with R Shiny and powerful network analysis libraries, this tool provides researchers with an intuitive interface to explore complex biological networks in a tissue-specific context.

Scientific Impact: Understanding tissue-specific protein interactions is crucial for elucidating tissue-specific biological functions, identifying potential tissue-specific drug targets, discovering novel biomarkers, and advancing precision medicine approaches.

Technical Specifications

Technology Stack

R Shiny igraph visNetwork SQLite dplyr HTML/CSS/JavaScript

Architecture

Backend: R Shiny server with igraph for network analysis and computation

Database: SQLite for storage and retrieval of tissue-specific interaction data

Visualization Engine: visNetwork for interactive network rendering and manipulation

Data Structure: Graph-based representation of protein interactions with tissue annotations and metadata

Purpose

TissuePPI is a web application designed to facilitate the exploration and analysis of tissue-specific protein interaction networks. It allows researchers to investigate protein interactions within specific tissues, providing insights into the functional organization of cells and tissues.

Methodology

The tissue-specific protein interaction networks in TissuePPI are constructed using a multi-step process. First, we integrate protein interaction data from String DB, which includes experimental data, text mining, gene co-expression, and curated databases. Second, we incorporate tissue-specific gene expression data to filter and refine the interactions, retaining only those relevant to the selected tissue. Finally, we apply network analysis techniques to identify key proteins and interactions, providing a comprehensive view of the tissue-specific interactome.

Data Sources

  • Protein Interaction Databases: Data from String DB V12 that integrates interaction information from various databases such as IntAct, Mint, and Bind..
  • Gene Expression Data: Tissue-specific gene expression data from GTEx projects V8 are used to filter interactions and ensure tissue relevance.
